## 🎮 Featured Games  

### 🐍 **Snake Game**
A classic Snake game built using **HTML, CSS, and JavaScript**.  
Students learn:
- Keyboard controls  
- Grid rendering  
- Game loops (`setInterval`)  
- Collision logic  

`![Snake Game](./Games/Snake/screenshot.png)`

---

### 🧱 **Breakout Game**
Break bricks with a bouncing ball and paddle!  
Students learn:
- Canvas API  
- Animation using `requestAnimationFrame`  
- Collision detection  
- Score tracking  

`![Breakout Game](./Games/Breakout/screenshot.png)`

2. Right-click → **Open with Live Server**
